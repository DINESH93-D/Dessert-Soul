# Dessert & Soul — Cafe E-commerce Frontend

A responsive cafe storefront demo built with HTML, CSS, JavaScript and Bootstrap 5.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Internet is needed for Google Fonts, Bootstrap CDN, Unsplash photos and the daily quote API.

## Features
- Responsive desktop/tablet/mobile layout
- Menu category filters and live search
- Add-to-bag, quantity controls and subtotal
- Demo checkout with client-side validation
- Newsletter email validation
- Daily quote loaded using `fetch()` from DummyJSON (with fallback)
- Bootstrap 5 navbar and responsive layout utilities

## Important
This is a front-end demo. Checkout does not process payments or create a real order.
Replace the sample cafe location, hours, menu, images and contact details before publishing.
